# DayzTraderLocalTool
Инструмент для владельцев DayZ-серверов и моддеров. Загружает папку `@Trader`, разбирает конфиги, показывает трейдеров и категории, находит ошибки, помогает исправлять цены, ID, NPC-точки, технику и VehicleParts.  Работает локально в браузере. Без облака, без аккаунта, без установки.
