# Changelog

## 0.1.0 - 2026-08-16

- Первый GitHub-пак программы.
- Локальный редактор Trader без серверной части.
- Разбор `TraderConfig.txt` и подключенных `<OpenFile>`.
- Проверка ID трейдеров, NPC-точек, цен, дублей, техники и VehicleParts.
- Инструменты переноса техники в отдельный `TraderConfig_Vehicles.txt`.
- Журнал задач, прогресс операций и отчет проверки.
- Встроенный гайд по работе с Trader.
